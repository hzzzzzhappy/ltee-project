# Code of conduct

the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).

Report unacceptable behaviour to Hanzhe Liang at hanzhe.liang@mbzuai.ac.ae.

This page adopts the linked policy by reference; the reporting contact is
specific to this classroom project.
