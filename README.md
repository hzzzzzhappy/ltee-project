## Setup and reproduction

You need [Pixi](https://pixi.prefix.dev/latest/) and an internet connection.
The analysis pipeline runs on Linux and macOS. Run these commands from the
project root:

```bash
pixi install --locked --all
pixi run reproduce
```

The `reproduce` task verifies the raw data, runs FastQC and MultiQC, then
aligns reads and calls variants. The MultiQC report is
`results/qc/multiqc/multiqc_report.html`; final variants are in `results/vcf/`.
Exact package versions are recorded in `pixi.lock`.

Repository: <https://github.com/hzzzzzhappy/ltee-project>.

The included GitHub Action installs the locked environment and runs
`reproduce` on each push. The Lesson 05 pipeline has been tested locally;
its GitHub check has not yet run.

## What is where

| Folder | What goes in it | Rule |
|--------|-----------------|------|
| `data/raw/` | Data exactly as you received it | Read-only. Never edit; download it with a script. Not committed. |
| `data/processed/` | Data derived from raw data | Regenerated by code. Not committed. |
| `metadata/` | Sample sheet, data sources, checksums, data dictionary | Small text files, committed. |
| `scripts/` | Code you write (Python, shell) | Committed. |
| `config/` | Parameters for the analysis or workflow | Committed. |
| `workflow/` | Snakemake and Nextflow pipelines | Committed. |
| `notebooks/` | Jupyter notebooks for exploration | Committed, outputs cleared or small. |
| `reports/` | Quarto documents that turn results into a report | Source committed, rendered HTML not. |
| `results/` | Figures, tables, logs made by the code | Regenerated. Not committed. |
| `docs/` | Longer documentation | Committed. |
| `envs/` | Conda `environment.yml` exports, for people without Pixi | Generated from `pixi.toml`. |
| `containers/` | Dockerfile and Apptainer recipe | Committed. |

Each folder has its own `README.md` with more detail.

## Data

Raw reads: a subset (175,000 read pairs per sample) of three *E. coli* clones
from the Long-Term Evolution Experiment (population Ara-3, generations 5,000,
15,000 and 50,000), prepared by Data Carpentry:
<https://doi.org/10.6084/m9.figshare.7726454> (file `sub.tar.gz`, CC0).
Reference genome: *E. coli* B str. REL606, GenBank CP000819.1 (NCBI).
Data sources, the three-sample sheet, a data dictionary and SHA-256 checksums
are in `metadata/`. The six FASTQ files and compressed reference genome have
been downloaded, checksum-verified and made read-only. They are excluded from Git.

## Data availability

The original sequencing runs SRR2589044, SRR2584863 and SRR2584866 are available
under NCBI BioProject [PRJNA295606](https://www.ebi.ac.uk/ena/browser/view/PRJNA295606).
The trimmed, subsampled reads used here are available from Data Carpentry on
figshare, <https://doi.org/10.6084/m9.figshare.7726454> (`sub.tar.gz`, CC0).
The reference is *E. coli* B REL606, accession CP000819.1, assembly
GCA_000017985.1, downloaded from NCBI. Exact URLs and provider MD5 checksums are
recorded in `metadata/sources.tsv`; checksums of the retained raw files are in
`metadata/checksums.sha256`.

The analysis code is available in this repository; see
[third-party notices](docs/third-party-notices.md) for source attributions and
licenses. Run `pixi run download` to retrieve and verify the raw data.
Derived results are generated locally by `pixi run reproduce` and excluded
from Git.
